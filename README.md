## 🧑‍💻 About Me

<p align="center">
  <img src="./assets/developer-card.svg" alt="Terminal-style card: Chathupa Chamika, recent ICET Institute graduate, learning the MERN stack, focused on full-stack development and PHP, familiar with Java, JavaScript, Angular and Spring Boot" width="100%"/>
</p>

I enjoy turning ideas into working web applications and learning by building them. **Full-stack development** and **PHP** are my current focus, and I'm learning the **MERN stack** alongside them — parallel paths, not replacements for each other.

**🎯 Current focus** — Full-stack application development · PHP-based development · modern web application architecture

**🔭 Learning direction** — MERN stack (MongoDB, Express, React, Node.js) · Laravel · cloud deployment with AWS

**🧭 Development principles**
- **Learn by building** — projects teach faster than tutorials
- **Write maintainable code** — readable today, changeable tomorrow
- **Design with users in mind** — interfaces should feel obvious
- **Improve through experimentation** — iterate, measure, refine
